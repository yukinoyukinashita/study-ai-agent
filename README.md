# 学习整理智能体项目
基于 Coze 开发的大学生学习整理AI Agent，用于课程知识点梳理、复习计划生成与学习资料整理。

## 项目功能
- 课程知识点结构化整理
- 期末复习计划自动生成
- 学习资料快速总结

## 技术实现
- 使用 Coze 平台搭建
- 基于大模型实现对话与知识处理
- 包含工作流与测试用例

# 个人AI开源项目合集

## 一、AI大模型聚合平台
### 项目简介
轻量化多模型聚合平台，整合多家大模型接口，支持多模型一键切换、连续上下文对话、自定义接口配置。
适合个人开发实战、接入大模型服务部署学习使用，架构简单易部署、易二次开发。

### 核心功能
- 多厂商大模型统一聚合管理
- 智能连续对话，上下文记忆
- 接口灵活配置，可快速新增模型
- 适配电脑/手机端，轻量化
